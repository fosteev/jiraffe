# Jiraffe 🦒

Расширение VS Code для повседневной работы с Jira без браузера: найти свои задачи,
прочитать задачу целиком (описание, вложения, комментарии, история), посмотреть
и залогать время (в том числе Tempo), пройтись по эпикам и релизам.

Сделано под реальное использование, а не под весь функционал Jira: в первой версии
только чтение и журнал работ. Смена статусов и создание задач — позже.

## Поддерживаемые инстансы

Несколько Jira одновременно, каждая со своей авторизацией:

| Тип | Авторизация | Особенности |
|---|---|---|
| Jira Server / Data Center 8.22+ | Personal Access Token (`Authorization: Bearer`) | возможен context path (`https://host/jira`); assignee — `{"name": login}` |
| Jira Cloud | Basic `email:API token` | поиск через `/rest/api/2/search/jql` (курсорная пагинация); пользователи по `accountId` |

Токены хранятся в VS Code SecretStorage, не в settings.json.

## Функции (MVP)

### 1. Инстансы и авторизация
- [ ] Добавить / удалить / переключить инстанс (URL, тип Server/DC или Cloud, токен)
- [ ] Проверка подключения (`/rest/api/2/myself`)
- [ ] Несколько инстансов в дереве одновременно

### 2. Поиск задач и фильтры
- [ ] «Открытые на мне» — по каждому инстансу
- [ ] Задачи по проекту (выбор проекта из списка)
- [ ] Быстрые фильтры: статус, тип задачи, исполнитель, приоритет
- [ ] Произвольный JQL
- [ ] Сохранённые фильтры (свои) и избранные фильтры из Jira
- [ ] Поиск по ключу (`GARM-123`) и по тексту
- [ ] Подгрузка длинных списков (пагинация)

### 3. Карточка задачи
- [ ] Шапка: ключ, заголовок, тип, статус, приоритет, ссылка «открыть в браузере»
- [ ] Люди: автор, исполнитель, наблюдатели
- [ ] Описание — отрендеренным HTML (`expand=renderedFields`)
- [ ] Эпик, fix version, метки, компоненты, подзадачи, связанные задачи
- [ ] Комментарии: автор, дата, текст

### 4. Вложения
- [ ] Список вложений: имя, размер, автор, дата
- [ ] Превью картинок прямо в карточке (скачиваются расширением с авторизацией)
- [ ] Открыть / скачать файл (в папку проекта или temp)

### 5. История задачи
- [ ] Лента изменений: кто, когда, какое поле, было → стало (`expand=changelog`)

### 6. Журнал работ и Tempo
- [ ] Список записей по задаче: кто, сколько, когда, комментарий
- [ ] Залогать время: длительность, дата, комментарий
- [ ] Tempo (где установлен): запись через `/rest/tempo-timesheets/3/worklogs/`, рабочие атрибуты (`/rest/tempo-core/1/work-attribute`), в т.ч. «AI Tokens»
- [ ] Где Tempo нет — стандартный `/rest/api/2/issue/{key}/worklog`
- [ ] Сводка «сколько я залогал сегодня / за неделю»

### 7. Эпики
- [ ] Список эпиков проекта
- [ ] Задачи эпика с прогрессом (сколько закрыто / всего)
- [ ] Server/DC: связь через кастомное поле `Epic Link` (id поля определяется для каждого инстанса); Cloud — через `parent`

### 8. Релизы
- [ ] Версии проекта: выпущенные / невыпущенные, даты (`/rest/api/2/project/{key}/versions`)
- [ ] Задачи релиза (`fixVersion = X`) и прогресс (`/rest/api/2/version/{id}/relatedIssueCounts`)

## Позже (не в MVP)
